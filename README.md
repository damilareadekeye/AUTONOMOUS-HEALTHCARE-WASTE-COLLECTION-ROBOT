# Autonomous Healthcare-Waste Collection Robot

IEEE Rwanda Mentorship Program — simulation baseline.

Stack: Ubuntu 24.04 · ROS 2 Jazzy · Gazebo Harmonic · Nav2 · AprilTag

Goal: receive a task, navigate to a collection point, verify the container (AprilTag),
simulate pickup, transport to storage, release, and report completion.

See `docs/` for setup instructions and test results.
